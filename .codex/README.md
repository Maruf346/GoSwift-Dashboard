# .codex — AI development context

This folder contains machine-readable guidance and context for AI assistants working on this project.

- `ai-direction.md` — high-level instructions for AI agents (how to fetch Figma, coding conventions, goals).
- `figma-usage.md` — concrete steps and constraints for using the Figma MCP server and design-to-code flow.
- `ui-quality.md` — pixel-perfect checklist and verification steps to ensure UI matches Figma.
- `api-guidelines.md` — REST API design patterns, endpoints, and security considerations.
- `deploy-aws-s3.md` — build and publish instructions for deploying the frontend to AWS S3 + CloudFront.

When invoking an AI agent to implement UI from a Figma link, point it at these files first.
